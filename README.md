## 💻 Cara Menjalankan Secara Lokal

1. Clone repositori ini atau download sebagai ZIP:
   ```bash
   git clone https://github.com/bagasran/portofolio.git
   ```
2. Buka folder proyek dan klik dua kali berkas `index.html` untuk membuka di browser apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox).
3. Untuk mencetak CV dalam format PDF, buka file `assets/cv-bagas.html` dan tekan `Ctrl + P` &rarr; pilih *Save as PDF*.
