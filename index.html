TENTANG SAYA

Menjembatani Kebutuhan Bisnis & Solusi Teknologi

Halo! Saya Bagas Randika Pratama, lulusan program studi D-III Manajemen Informatika dari Universitas Logistik dan Bisnis Internasional (ULBI) Bandung dengan predikat Cum Laude (IPK 3,73). Saya memiliki ketertarikan kuat dalam menghubungkan proses bisnis operasional dengan solusi teknologi informasi yang efisien dan terstruktur.

Melalui pengalaman kerja sebagai System Analyst & Web Developer di PT. Swamedia Informatika, saya terbiasa melakukan analisis kebutuhan bisnis secara mendalam—mulai dari pemodelan alur kerja dengan BPMN 2.0, perancangan arsitektur sistem berbasis UML (Use Case, Class, Activity, Sequence Diagram), analisis akar masalah menggunakan Diagram Ishikawa & 5-Whys, hingga evaluasi kualitas sistem menggunakan kerangka kerja PIECES dan Model KANO.

Selain analisis sistem, saya memiliki kemampuan teknis dalam membangun aplikasi web berbasis cloud menggunakan Next.js 15, TypeScript, Supabase (PostgreSQL), serta PHP Native & MySQL, didukung pengujian terstandarisasi Black Box Testing (Boundary Value Analysis) dan otomasi Katalon Studio. Saya juga menguasai pemeliharaan perangkat kerja, troubleshooting hardware, serta instalasi dan konfigurasi sistem pada lingkungan Windows OS.
